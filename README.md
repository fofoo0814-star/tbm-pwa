# 작업 전 TBM 안내페이지 PWA v2

## 개요
모바일 웹 기반 TBM 안내페이지 시제품입니다.

근로자는 최초 1회 QR코드로 접속한 후, 휴대폰 홈 화면에 바로가기 아이콘을 생성하여 이후 QR코드 없이 접속할 수 있습니다.

## 파일 구성
- index.html: 화면 구조 및 기능
- data.js: TBM 문구 수정 파일
- manifest.json: 홈 화면 아이콘 및 PWA 설정
- sw.js: 오프라인 캐시 설정
- icons/: 홈 화면 아이콘 이미지

## 문구 수정 방법
TBM 문구는 data.js 파일에서 수정합니다.

## 주의사항
- 현재 확인 완료 기록은 사용자의 기기에만 임시 저장됩니다.
- 실제 권역별·사업장별 확인률 집계를 위해서는 사내 설문, 승인된 폼, 또는 별도 저장시스템 연계가 필요합니다.
- 개인정보, 내부 보안자료, 비공개 업무자료는 외부 공개 웹페이지에 포함하지 않는 것이 원칙입니다.
- 정식 운영 전 정보보안 및 개인정보 보호 검토가 필요합니다.
