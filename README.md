# PWA형 TBM 안내앱 시작파일

## 구성
- index.html: 메인 화면
- manifest.json: 앱 설치 정보
- sw.js: 오프라인 캐시용 서비스워커
- icons/: 앱 아이콘

## 사용 방법
1. 압축을 풉니다.
2. index.html을 더블클릭하면 화면을 확인할 수 있습니다.
3. PWA 설치 기능은 일반 파일 실행에서는 제한될 수 있습니다.
4. 실제 배포 테스트는 HTTPS 서버, GitHub Pages, 사내 웹서버 등에 올려서 확인하는 것이 좋습니다.

## 내용 수정
TBM 문구, 스트레칭, 보호구 체크, 응급상황 대응 내용은 index.html 안에서 수정하면 됩니다.
